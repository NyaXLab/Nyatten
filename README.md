# にゃってん
[Atten](https://atten.win)をちょっぴり便利にします。
# 機能一覧
・NGワード  
・NyaXEmojiの表示  
・EmojiPicker  
・アクティブインジケータ。相手もNyattenを利用している必要があります  
・2クリックでアカウントにログイン  
・Attenがプレビューできない一部ファイルの拡張プレビュー  
・Mirotalkに直接参加  
・埋め込みのTurboWarpプレイヤーにユーザーIDを適応
# 導入方法
1. [最新のnyatten.zip](https://github.com/nyantorusabu/Nyatten/releases/latest)をダウンロード  
2. 解凍  
3. GoogleChromeで`chrome://extensions`を開き「デベロッパーモード」を有効にし先ほど解凍したフォルダを選択  
※解凍したフォルダを消すと拡張機能が消えます。
# NAPで取り寄せる
1. `npm install -g @nyaitter/nap`でnapを入れる  
2. `nap get NyaXLab/Nyatten`で取り寄せる  
3. Google Chromeで`chrome://extensions`を開き「デベロッパーモード」を有効にする  
4. 「パッケージ化されていない拡張機能を読み込む」から、取り寄せたフォルダの中の`extension`フォルダを選択  
更新するときは取り寄せたフォルダを消し、`nap get NyaXLab/Nyatten`をもう一度実行します。
# 設定の変更方法
Nyattenが有効な状態でAttenの設定を開くと色々変更できます。
